# Pruebas de contratos

Estas pruebas validan la estructura versionada de notebooks, bundles, workflows,
documentación y archivos de configuración sin ejecutar infraestructura externa.

La descripción de cada contrato y las reglas para evitar pruebas textuales
frágiles están en la sección [Pruebas de contratos](../../docs/testing.md#pruebas-de-contratos)
de la documentación general.
