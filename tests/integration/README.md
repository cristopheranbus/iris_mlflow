# Pruebas de integración

Estas pruebas ejercitan MLflow con SQLite, archivos temporales y el flujo local.
Nunca acceden a Databricks ni a servicios de red.

La descripción de cada archivo, sus límites y criterios de incorporación están
en la sección [Pruebas de integración local](../../docs/testing.md#pruebas-de-integración-local)
de la documentación general.
